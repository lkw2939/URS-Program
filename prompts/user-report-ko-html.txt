첨부한 원본 URS 또는 기술 사양서 PDF를 한국어로 번역하고,
완성된 HTML/CSS 문서로 제작해줘.

이전에 작업한 3M RFQ HTML처럼
원본 페이지별로 구분하고, 깔끔한 기술 보고서 디자인을 적용해줘.

단, 이전 문서의 페이지 수, 설비명, 제품명, 수치, 모델명,
그림 위치 또는 기술 요구사항을 이번 문서에 가져오지 말고
반드시 이번에 첨부한 원본을 기준으로 새로 작성해줘.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 번역 원칙
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- 원본의 내용을 요약하지 말고 한국어로 빠짐없이 번역해줘.
- 제목, 본문, 목록, 표, 각주, 사진 설명, 도면 표기,
  경고문 및 부록까지 확인해줘.
- 각 원본 페이지의 내용이 해당 한국어 페이지 구역에
  빠짐없이 들어가도록 해줘.
- 숫자, 단위, 공차, 범위, 최소·최대 조건, 시험 시간,
  성능 기준 및 수량을 정확하게 유지해줘.
- 모델명, 설비명, 제품명, 부품번호, SKU, 문서번호,
  표준번호, 파일명, 연락처 및 개정번호를 정확하게 보존해줘.
- 필수사항, 권고사항, 허용사항 및 금지사항의 의미 차이를 유지해줘.
- 공급업체, 구매자, 사용자, 작업자 등 요구사항의 책임 주체를
  임의로 바꾸지 말아줘.
- 원문에 없는 내용은 추측해서 추가하지 말아줘.
- 확인하기 어려운 글자나 숫자는 임의로 확정하지 말고
  “원본 확인 필요”라고 표시해줘.
- 원문에 서로 다른 수치나 표현이 있으면 임의로 통일하지 말고,
  각각 원문대로 번역한 후 확인이 필요하다고 주석을 달아줘.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. 페이지별 구성
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- 첨부된 원본 PDF의 실제 페이지 수를 확인해줘.
- 원본 페이지마다 독립된 한국어 페이지 구역을 만들어줘.
- 각 구역에 원문 페이지 번호를 표시해줘.
- 이미지나 도면만 있는 페이지도 생략하지 말아줘.
- 표가 여러 페이지에 걸쳐 있으면 원문의 연결 관계를 유지해줘.
- 원본 레이아웃을 그대로 복사할 필요는 없지만,
  원문과 한국어 문서를 페이지별로 쉽게 대조할 수 있게 해줘.
- 번역문이나 도면이 길어 실제 인쇄 시 한 장에 들어가지 않더라도
  내용을 삭제하거나 글씨를 지나치게 줄이지 말아줘.
- 해당 원문 페이지의 내용이 다음 인쇄 페이지로 이어질 경우에도
  원문 페이지 소속이 명확하도록 표시해줘.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3. 사진 및 기술 도면
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

기존 3M HTML처럼, 사용자가 문서 상단에서 원본 PDF를 선택하면
원본의 사진과 기술 도면이 해당 한국어 페이지에 표시되도록 만들어줘.

- 원본 PDF를 브라우저에서 직접 선택할 수 있게 해줘.
- 선택한 PDF는 브라우저에서 처리하고,
  PDF 파일을 별도 서버로 업로드하는 코드는 넣지 말아줘.
- PDF.js 등을 사용하여 각 페이지를 렌더링해줘.
- 새 PDF를 직접 확인하여 사진과 도면의 페이지 및 영역을 지정해줘.
- 이전 문서의 이미지 좌표를 그대로 사용하지 말아줘.
- 도면의 치수, 제목, 범례 및 중요 영역이 잘리지 않게 해줘.
- 이미지 비율을 왜곡하지 말아줘.
- 도면 안의 영어는 원본으로 보존하고,
  필요한 경우 아래에 한국어 대응표를 제공해줘.
- 원본 그림을 표시할 수 없는 경우 임의로 대체 도면을 만들지 말고,
  표시할 수 없다는 사실을 명확히 알려줘.
- 원본 PDF 선택이 필요하다는 점을 HTML 상단에 표시해줘.
- PDF.js를 외부에서 불러온다면 인터넷 연결이 필요하다고 표시해줘.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4. 디자인 및 배치
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

기존 HTML과 유사한 전문 기술 보고서 형식으로 만들어줘.

- 흰색 문서 바탕.
- 남색 또는 파란색 계열의 제목과 구분선.
- 표지, 제목, 소제목, 목록, 표가 명확히 구분되는 구성.
- 중요한 수치와 기술 요구사항은 굵게 표시.
- 번역 주석이나 확인 필요 사항은 별도 박스로 구분.
- 적절한 문단 간격과 여백.
- 원본과 같은 레이아웃은 유지하지 않아도 됨.
- A4 인쇄를 고려한 CSS 포함.
- 브라우저에서 읽기 편하고 전문적인 디자인.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5. 최종 검수
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

최종 출력 전 아래 사항을 점검해줘.

- 원본 페이지가 빠짐없이 반영되었는가?
- 페이지별 본문과 표의 내용이 누락되지 않았는가?
- 숫자, 단위, 조건 및 모델명이 정확한가?
- 사진과 도면이 원본의 올바른 위치에 대응하는가?
- 작은 글자를 추측해서 임의로 채우지 않았는가?
- 원문의 요구사항과 번역자 주석이 구분되는가?
- HTML을 브라우저에서 열 수 있는가?
- 인쇄 시 내용이 겹치거나 잘리지 않도록 구성했는가?

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
6. 출력 형식
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- 설명이나 요약이 아닌 실제 완성 HTML 코드를 출력해줘.
- <!DOCTYPE html>부터 </html>까지 전체 코드를 제공해줘.
- CSS와 필요한 JavaScript는 HTML 안에 포함해줘.
- 내용을 “이하 생략”으로 줄이지 말아줘.
- 이미지 표시를 위해 원본 PDF 또는 인터넷 연결이 필요하면
  HTML 안에 사용 방법을 명확하게 적어줘.
