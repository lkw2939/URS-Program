# 독립검증 결과와 선택 수정

## 현재 동작

보고서 검토 → 독립검증 결과 보기에서 한국어 HTML 화면을 엽니다. 상단에는 이름·저장 버전·한국시간 검증 일시, 오류/확인 필요 건수와 다음 행동을 표시합니다. 각 항목은 원문 쪽, 문제, 중요성, 수정 방법, 현재/권장 문장 비교, 접힌 영어 근거 순서입니다. 표시 차이만인 관찰은 별도로 접고 오류 수에 넣지 않습니다. 과거 결과에 한국어 근거·심각도·수정문이 없으면 기록이 없다고 표시하며 새 판단을 발명하지 않습니다.

실제 송신은 OpenAI 요청 생성 직후의 request.data에서 식별합니다. 원본 PDF 파일, 저장 최종 HTML의 텍스트 입력(본문·표·CSS 포함, base64 그림 주소만 전송용 ID로 대체), 원래 PNG bytes의 별도 input_image가 전달됩니다. 변환 PDF는 이 경로에 사용하지 않습니다. 송신 파일·이미지·텍스트와 전체 요청의 해시, 건수, HTTP 상태를 기록하고 키/문서 본문은 기록하지 않습니다. 과거 결과에 manifest가 없으면 전송 형식은 미확인입니다. 결과 화면 자체가 HTML이라는 사실과 입력 형식을 구분합니다.

## 명시적 수정

기존 구현은 모델 수정안을 읽는 기능만 있었습니다. 이제 오류 항목을 선택하고 수정 전후 확인을 누르면 적용 계획만 저장합니다. 선택한 수정 적용을 별도로 눌러야 새로운 URS 보고서 버전을 만듭니다. 기존 보고서, raw Terra HTML, 검증 기록, 승인/직원 답변은 유지합니다. 새 버전에는 승인·검증 통과를 복사하지 않습니다. 확인 필요 또는 서식 차이 항목은 적용하지 않습니다.

수정은 지정 쪽의 단일 본문 텍스트 범위에만 정확히 매칭합니다. 반복·여러 태그·미확인 쪽·겹치는 수정은 추측하지 않고 거절하며 문제 표현 단위로 좁히라고 안내합니다. 수정문을 HTML 이스케이프하여 태그/CSS/속성/스크립트 삽입을 막습니다. 삭제는 별도 명시가 필요합니다. 최신 대상/실행/해시와 소유자, 원본 PDF 무결성을 다시 확인합니다. A4 검사 PASS 보고서는 수정 후에도 페이지 넘침·이미지 표시를 재검사하고 실패하면 적용하지 않습니다. 옛 A4 미확인 보고서를 임의로 보정하지 않습니다.

예: 저장 버전1, 실패한 생성 시도2가 남아 있으면 버전1을 부모로 새 버전3을 만듭니다. 직원이 버전을 선택하거나 외부 A4 파일을 올릴 필요가 없습니다. correction-patch에는 부모 해시와 적용 위치/문구를 저장하고 무결성 검사 시 부모에 동일 패치를 재현해 최종 bytes와 비교합니다. raw HTML은 Terra의 수정 전 원본임을 별도 표시합니다. 백업 복원에서도 이 연결을 확인합니다.

적용 후 수정된 보고서 보기와 독립 재검증 실행이 새 현재 보고서에 자동 연결됩니다. 수정 전 결과를 수정본 결과로 재사용하지 않으며 이전 화면에 명확히 표시합니다. 수정본 독립검증 PASS 전에는 기술분석이 차단되고 이유를 보여 줍니다. 메인 보고서 화면은 BroadcastChannel로 저장 대상 변경을 반영합니다.

## 비용과 실행

별도 비용 확인 버튼을 필수로 누르지 않습니다. 실행 버튼 안에서 실제 입력의 무료 토큰 계산 → 1회 예상 상한과 실행 한도 확인 → 명시적 시작 → 비동기 실행/진행 조회 순서입니다. 이미 같은 입력의 비용을 확인했다면 중복 확인하지 않습니다. 취소하면 추론 호출이 없습니다. OpenAI 잔액과 로컬 실행 한도는 별도입니다. 무제한 응답 대기와 자동 유료 재시도 없음은 유지합니다.

## 모의 확인

- test_corrections.py: 정확한 본문 수정, 확인 필요/서식 차이 거절, 중복/모호 범위 거절, HTML 이스케이프, 명시적 삭제, 소유권/오래된 대상 거절, 중복 적용 방지, 이전 이력 보존, 백업·복원·변조 감지.
- browser_correction_flow.py: 실제 로그인·버튼 → 모의 요청 manifest → 한국어 결과 → 수정 전후 확인 → 선택 적용 → 새 보고서 팝업에서 사진 표시 → 수정본으로 재검증 → 새 결과 HTML → 기술분석 활성화.
- browser_immediate_images.py: 실제 생성 경로 모의 응답, HTML 확인 클릭, 원본 사진 2개의 서로 다른 픽셀과 벡터 도면 확인, JS 없는 오프라인 다운로드에서도 표시. 원본 재선택/PDF.js 없음.

모든 데이터는 임시 DB/합성 PDF입니다. 운영 SG6를 재생성하거나 유료 호출·예산 증액·원장 초기화를 하지 않았습니다. 제공된 외부 주소의 읽기 전용 GET은 HTTP 404였고, 연결된 GitHub 계정의 Codespaces 목록은 비어 있었습니다. 따라서 운영 적용과 실제 SG6 화면의 사진 표시는 미확인입니다. main 소스 적용 후 python start.py로 재시작해야 하며, 소스 푸시만으로 운영 재시작을 주장하지 않습니다.

최종 전체 시험: 단위·HTTP 213개와 실행기 10개 모두 exit_code=0, 수집된 현재 소스 및 증거 해시 일치. 실제 유료 API/운영 문서 검증은 실행하지 않았습니다.
