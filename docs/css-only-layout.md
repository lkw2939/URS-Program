# <style> 내부만 수정하는 배치 편집

수동 CSS 편집 요청은 원본 PDF를 배치 참고로만 사용하며 기존 번역을 다시 만들지 않습니다. 같은 모델에 전달하는 수동 편집 지시를 별도로 분리했습니다. 기존 HTML 전체 반환, 기존 style 요소의 내용만 변경, 태그·본문·수치·표·캡션·주석·링크·쪽번호 문구·요소 순서·그림 src 및 순서 유지가 필수입니다. 보고서 쪽수는 해당 문서 기준이며 SG6의 25쪽을 다른 문서에 강제하지 않습니다.

`urs/css_only.py`는 기존 style 요소의 내부 텍스트만 마스킹한 뒤 나머지 문자열 배열을 정확히 비교합니다. 태그 추가/삭제, style 태그의 속성 변경, 본문 재들여쓰기, 이미지 속성 재표기까지 거절합니다. 이전의 텍스트/그림 순서 검사도 유지합니다. 모델 응답은 프로그램이 원본 그림 주소를 복원한 전송용 입력과 비교하며, 통과 후 이미지 주소만 원래 PNG로 연결합니다. 기존 보고서와 독립검증 기록은 보존합니다.

CSS 수정이 완료된 뒤에는 기존 최종 보고서 버튼 외에 `CSS 수정 결과 보기` 링크를 직접 표시합니다. 재접속해도 저장된 수정 작업의 결과 버전으로 연결됩니다. 로그인된 브라우저의 실제 버튼 실행부터 새 링크로 결과 열기, 원래 보기 버튼과 다운로드가 같은 새 버전을 가리키는지 모의 응답으로 확인합니다. 운영 서버 적용을 추정하지 않습니다.

별도의 비공개 확인용 파일은 실제 SG6 버전2 전체 HTML을 바탕으로 기존 style 내부에만 쪽별 CSS를 추가했습니다. 원본 PDF의 표지/2/4/9/12/17/18/22/24쪽을 배치 참고로 확인했습니다. CSS 외부 문자열의 SHA-256이 원본과 동일하며, 사진 28개와 링크·표·본문·inline style·태그 순서를 그대로 보존합니다. Chromium 검사에서 25개 A4 세로 구역·사진 28개 표시·넓은/좁은 화면 및 스크립트 켬/끔에서 넘침/잘림 없음으로 확인했습니다. 17·18쪽 등 대표 페이지도 화면으로 확인했습니다. 이 파일은 직접 CSS를 조정한 확인용 사본이며 실제 Terra 새 호출 결과나 운영 등록 결과로 표시하지 않습니다. 고객 원본·HTML·스크린샷은 공개 저장소와 소스 패키지에서 제외합니다.

최종 회귀: 단위·HTTP 252개, 실행기 13개 모두 exit code 0. 현재 소스·증거 지문 일치.
