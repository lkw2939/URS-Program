# Terra가 배치를 작성하고 다듬는 생성 경로

## 생성·이미지·배치의 역할

새 `Processing.report`는 프로그램의 `a4_pages.paginate`를 호출하지 않습니다. 최초 모델 요청에 원본 PDF, 저장 프롬프트 원문, 이미지 식별 주소/쪽/영역과 실제 PNG width_px·height_px·aspect_ratio, A4 출력 요구를 전달합니다. PDF의 이미지와 크기 정보를 처음부터 고려해 HTML/CSS 배치를 작성하도록 합니다. 기존 이미지 PNG를 줄이거나 다시 압축하지 않습니다.

프로그램은 모델 HTML의 `urs-image:쪽:번호` 주소만 원본 PNG data URL로 치환합니다. 새 생성에서는 프로그램이 CSS/문단/표를 고치거나 사진 크기를 다시 정하거나 장을 나누지 않습니다. 과거 A4 자동 분할 함수는 기존 저장본의 버전/지문 호환을 위해 남아 있지만 새 생성 경로에서 실행하지 않습니다.

사진 연결 후 기존 Chromium 검사로 A4 가로·세로, 넘침, 잘림, 작은 글자, 사진 로딩·숨김을 확인합니다. 정상 최초 응답은 추가 호출 없이 저장합니다. 배치 문제일 때만 해당 원문 쪽의 실제 PNG 스크린샷, 전체 최초 HTML(urs-image 주소), 문제 목록, 원본 PDF, 같은 저장 프롬프트와 이미지 크기 목록을 같은 모델·effort·max_output_tokens로 보내 최대 1회 다듬습니다. 문제 화면을 만들지 못하거나 원본 이미지 주소가 미연결이거나 HTML 문서 끝이 없으면 추가 유료 호출하지 않습니다.

모델이 다듬은 HTML의 원문 쪽별 본문/수치/표/캡션 토큰과 이미지 주소 순서를 최초 HTML과 비교합니다. 알려진 PDF 선택 안내/figure-status 같은 프로그램 로더 UI는 본문 비교 대상에서 제외합니다. 내용 또는 이미지가 달라지면 채택하지 않습니다. 프로그램은 수정 응답에도 이미지 주소만 연결하며 다시 표시/배치 검사를 통과한 결과만 정상 저장본으로 선택합니다. 1회 다듬기 후 실패하면 자동 재호출하지 않고 기존 정상 보고서를 유지합니다. 실제 의미 보존/번역 품질의 전문가 판정과는 별도의 기계적 보존 검사입니다.

## 비용·기록·기존 파일

최초 비용 화면에는 최초 요청의 예상 상한과 최대 1회 추가 다듬기 가능성을 표시합니다. 다듬기 입력은 생성 후에야 확정되므로 그때 실제 PDF·HTML·스크린샷 요청으로 무료 토큰 계산을 합니다. 최초 호출의 확인된 실제 사용액(사용량이 없으면 예약 상한) + 다듬기 예상 상한이 같은 1회 실행 한도를 넘으면 추가 유료 호출하지 않습니다. 각 호출은 기존 사용량 정산 장부로 따로 기록하며, 예약액을 실제 지출로 합산하거나 미확인 사용량을 0원 처리하지 않습니다.

`report.raw.html`은 최초 모델 응답으로 보존됩니다. `report.refinement-response.html`은 다듬기 응답, `report.html`은 채택 응답의 이미지 주소만 연결한 직원용 결과입니다. `layout-refinement`에는 검사·스크린샷 지문·채택 여부·실패 이유와 호출 ID를 저장합니다. 실제 PNG 화면은 개별 artifact로 저장하며 로그에는 API 키나 문서 본문을 넣지 않습니다. API 진단의 task로 report_html과 report_layout_refine을 구분합니다. 저장본 재열람 시 최초 응답/채택 응답/최종 HTML/영수증 지문과 이미지 주소 치환 결과를 검증합니다. 기존 보고서·DB·프롬프트는 마이그레이션/교체하지 않습니다.

## 확인 범위

유료 호출 없이 임시 DB와 모의 HTTP를 사용했습니다. 실제 로그인 생성 버튼 -> 최초 불량 배치 응답 -> 사진 연결 -> 실제 화면 캡처 -> 같은 모델 설정의 모의 다듬기 요청 -> 본문 보존 -> 이미지 연결 -> 최종 저장 -> 직원용 보기 -> 동일 파일 다운로드 -> 오프라인·JavaScript 끔 렌더링까지 확인합니다. 25쪽 합성 자료는 25장 A4, 9쪽 도면과 23쪽 두 사진 포함 3개 그림이 표시되며 넘침이 없습니다. 프로그램 분할 스타일/코드가 최종 HTML에 추가되지 않음과 모델 응답 대비 src 외 bytes 일치도 확인합니다.

공개 결과 HTML/스크린샷은 합성 자료와 모의 모델 응답입니다. 실제 Terra가 만든 고객 SG6의 새 결과물이라고 표시하지 않습니다. 실제 모델 호출·고객 문서 품질·운영 서버 적용은 미확인입니다. SG6 재생성·독립검증·운영 데이터 쓰기는 하지 않았습니다. 관리 브라우저의 file:// 제한 때문에 다운로드 bytes를 독립 오프라인 문서로 렌더링하며, 직접 file:// 탐색을 실행했다고 주장하지 않습니다.

최종 회귀: 단위·HTTP 243개, 실행기 12개 모두 exit code 0. 현재 소스와 증거 지문 일치.
