# 독립검증 결과를 읽고 직접 수정하기

## 결과 분류와 내용

번역 오류만 수정 입력칸을 제공합니다. 고객 확인 항목에는 고객 질문을, 그림 주소·CSS·렌더링 항목에는 프로그램 점검을 표시합니다. 원문 자체가 모호한 경우를 임의의 확정 번역으로 바꾸지 않습니다. 쪽수·줄바꿈만 다른 항목은 번역 오류 수에서 제외합니다. 저장된 응답에 근거·영향 설명이 없으면 해당 빈 상자를 만들지 않으며 없는 판단 근거를 창작하지 않습니다. 제목과 같은 문제 문장은 중복 표시하지 않습니다. 비어 있는 source_en은 접힌 근거 상자도 만들지 않습니다.

번역 오류에 before/after가 저장되어 있으면 비교를 표시하고, 둘 다 없으면 ‘수정 문구 직접 입력’을 접어 둡니다. 고객 확인·프로그램 문제에는 수정 입력칸이 없습니다. 원문 두 쪽을 비교할 때는 페이지별 인용이 있는 쪽을 표시하며, 인용 없는 관련 쪽은 추가 대조 필요로 구분합니다. 원본 페이지 범위를 벗어난 번호는 근거로 승격하지 않습니다.

향후 독립검증 요청에도 issue_type, 짧은 한국어 문제·실무 영향·고객 질문, 쪽별 실제 영어 인용을 요구합니다. 원문 모호성이나 프로그램 문제에 수정 문구를 만들지 않도록 합니다. 이 프롬프트 변경을 검증하려고 실제 유료 요청을 새로 보내지는 않았습니다. 기존 기록의 빈 근거가 생겼다고 주장하지 않습니다.

## 직원 HTML과 전송 사본 비교

저장된 직원용 HTML에서 기존 전송 함수를 이용해 사본을 재현하고, 실제 요청 경계에서 기록한 HTML SHA-256과 비교합니다. 일치하는 경우에만 ‘실제 검증 사본’이라고 표시합니다. 이미지 주소를 마스킹한 나머지 모든 bytes가 동일한지 비교하므로 본문·CSS의 변경 여부도 구분합니다. staff의 내장 이미지 개수, 미연결 urs-image 주소, 숨김 선언 존재를 따로 확인합니다.

urs-review-image는 별도 이미지 입력을 연결하는 전송 식별자입니다. 이 주소가 있다는 이유로 직원 HTML의 이미지가 누락됐다고 판정하거나 번역문을 수정하지 않습니다. CSS 선언이 있다는 것과 실제 이미지에 적용돼 숨겨졌다는 것은 구분합니다. 실제 요청 사본의 해시가 없거나 불일치하면 위치를 미확인으로 표시합니다. 이 대조는 로컬 연산이며 API를 호출하지 않습니다.

## 문서·인쇄

결과 화면은 데스크톱에서 210mm 폭, 작은 화면에서는 읽을 수 있는 폭으로 표시합니다. @page A4 portrait와 인쇄 여백을 적용하고, 본문을 연속 흐름으로 인쇄합니다. 카드마다 페이지를 배정하거나 높이를 고정하거나 overflow로 잘라 맞추지 않습니다. 입력·실행 조작부는 인쇄에서 숨기고 실제 입력 문구는 전체 텍스트로 인쇄합니다. 근거 인용은 인쇄 시 펼칩니다. 빈 직접 입력란은 인쇄하지 않습니다. CSS를 결과 HTML에 내장해 다운로드한 결과도 A4 스타일로 읽습니다. 수정과 재검증은 로그인된 웹에서 수행합니다.

## 실제 직접 입력 저장 시험

16쪽 합성 PDF와 모의 AI 응답을 사용해 다음을 확인했습니다.

1. 로그인 후 결과 열기. 번역/고객 확인/프로그램 분류와 7쪽 질문, 12·16쪽 근거를 확인.
2. 현재 보고서에서 바꿀 문구를 직원이 직접 입력. 수정문을 비운 채 요청하면 명확한 오류가 나오고 보고서는 그대로임.
3. 모델 제안과 다른 한 문장 ‘시험 수행은 고객에게 권장되는 사항입니다.’를 직접 입력.
4. 전후 미리보기에서 입력한 두 문구를 확인. 이 시점까지 원래 보고서 변화 없음.
5. 선택 적용 후 새 버전3이 부모 버전1의 해당 문구만 정확히 바꾼 bytes인지 확인. 기존 버전1·실패 시도2·검증 기록 보존.
6. 수정된 보고서를 팝업으로 다시 열어 직접 입력 문장과 원본 이미지 3개가 실제 보이는지 확인.
7. 수정된 보고서 보기·독립 재검증 실행 연결과 현재 버전의 재검증 PASS 후 기술분석 활성화를 모의 확인.
8. 결과 인쇄물이 A4 세로 두 장이며 직접 입력 문장이 PDF 텍스트에도 남는지 확인. 화면 폭 210mm와 모바일 넘침도 확인.

직접 입력의 저장 검증을 UI만 바뀌었다는 증거로 대체하지 않았습니다. 삭제는 delete=true와 빈 대체 문구를 모두 요구하고, 대체 문구와 삭제 동시 선택은 거절합니다. 서버 입력 오류도 일반 PDF 오류로 뭉개지 않고 해당 수정 입력 오류를 반환합니다.

## 범위

실제 고객의 최신 SG6 독립검증 응답 전체는 현재 첨부 기록에 없으므로 그 결과의 판단 근거를 새로 확인했다고 주장하지 않습니다. 제공된 원본 PDF의 7·12·16쪽은 읽기 전용으로 참고했고 기존 보고서·검증 DB·직원 답변은 덮어쓰지 않았습니다. 실제 SG6 사진 포함 확인용 사본은 비공개 작업 폴더에서 28개 표시를 재확인했으며 저장소/패키지에 고객 자료를 포함하지 않습니다. 운영 적용과 유료 검증은 별도 미확인입니다.

최종 전체 시험: 단위·HTTP 228개와 실행기 10개 모두 PASS. 소스·증거 해시 일치. 저장 인용을 표시하는 것은 인용 자체의 원본 PDF 일치나 실제 고객 번역 품질을 별도로 인증했다는 뜻이 아닙니다.
