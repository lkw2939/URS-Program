# 웹 CSS·배치 다듬기와 화면 정리

보고서 검토에서 최신 저장 HTML을 대상으로 `CSS·배치 다듬기`를 한 번 실행합니다. 이전 정상 보고서를 보고 있더라도 더 최신의 검사 미완료 저장본이 있으면 그 파일이 대상이며 대상 버전을 명시합니다. 직원이 버전 드롭다운을 고르거나 외부 파일을 올리거나 새 번역을 생성하는 절차는 없습니다. 수정 요청을 선택적으로 입력하고 버튼을 누르면 기존 API 설정·1회 한도 안에서 실제 자료로 무료 입력 비용을 계산한 뒤 모델 호출 1회를 수행합니다. 무한 재시도하지 않습니다.

현재 보고서의 내장 PNG를 보관된 원본 그림 URI로 되돌린 전송용 사본, 영어 원본 PDF, 보관된 프롬프트, 실제 그림 크기/비율·영역 목록, 현재 화면 검사와 실제 페이지 스크린샷, 직원 수정 요청을 전달합니다. 반복되는 동일 로고 PNG도 원래 모델 슬롯 순서와 대조하여 원본 식별자를 복구합니다. 모델이 HTML/CSS 배치를 고치며 프로그램은 응답의 그림 주소만 원본 PNG로 연결합니다. 원문 쪽별 본문·수치·표·캡션과 그림 주소 순서가 바뀌면 거절합니다. 브라우저 실행이 불가능하면 유료 호출 전에 중단합니다. 머리말/쪽 번호/주석과 캡션은 12px 기준, 본문은 기존 13px 기준으로 검사하여 12px 쪽 번호를 본문 축소로 오인하지 않습니다.

성공하면 새 버전·원본 보존·모델 응답·최종 HTML·검사 자료·부모 버전 지문을 한 트랜잭션으로 저장합니다. CSS 수정 버전의 report.raw.html은 부모 저장 보고서의 그림 주소를 복구한 전송용 입력이며 최초 Terra 응답이라고 표시하지 않습니다. 과거 최초 Terra 응답은 부모 버전에 그대로 남습니다. 원본 PDF와 기존 HTML·승인·답변·검증 이력은 변경하지 않습니다. 실패하면 기존 저장본과 작업 버전이 유지되며 실패 이유가 남습니다. 독립검증·기술분석은 실행하지 않으며 새 보고서의 독립 재검증은 별도입니다. 작업 중 문서별 잠금과 큐 상태로 중복 실행을 막습니다. 서버 재시작으로 남은 진행 상태는 실패/중단으로 기록하고 자동 유료 재실행하지 않습니다.

## 웹 화면

기본 보고서 보기·HTML 다운로드·생성·CSS 다듬기·검증 실행/결과를 먼저 배치했습니다. 프로젝트 수 지표, 중복 내비게이션을 기본 화면에서 제거하고 AI/프롬프트 설정, 체크리스트/검증 기준/기술 진단/별도 파일 검토는 접힌 상세 영역으로 옮겼습니다. 파일 지문과 사진 정적 진단도 파일 상세에 모았습니다. 실제 생성의 시각(한국시간)·API 응답·출력 한도를 기본 화면에 표시하고 이전 생성 이력은 접어 보관합니다. CSS 작업의 접수·실행·실패·새 버전도 별도로 표시하고 최근 20개 이력에서 결과를 직접 열 수 있습니다.

새 생성이 확인 미완료일 때 이전 파일은 `이전 보고서 보기/다운로드 (새 결과 아님)`로 표시합니다. 최신 저장본 보기 링크를 별도로 표시하므로 ZIP을 받아야만 실제 새 HTML을 찾는 구조를 피합니다. ZIP/원문/JSON은 선택적 진단용으로 보존합니다. 서버가 아직 새 CSS API를 지원하지 않으면 버튼을 비활성화하고 업데이트/재시작 필요를 표시합니다. 검토 정보 로딩 중에는 클릭을 막고 로딩 상태를 표시합니다.

## 브라우저 실행 환경

`service.py restart`는 실행 중인 기존 서버를 종료하기 전에 실제 서비스 Python의 Playwright·Chromium 실행을 확인합니다. 필요할 때 잠금 파일의 Python 의존성과 Chromium/OS 의존성을 준비한 후 재검사합니다. 준비 실패 시 기존 서버를 종료하지 않습니다. 자동 시작의 수동 종료 설정은 유지합니다. 이 준비는 API를 호출하지 않습니다. 운영 적용/설치 성공 여부는 운영 서버에서 별도 확인해야 합니다.

## 시험 범위

임시 DB·로그인 브라우저에서 CSS 버튼 -> 모의 모델 응답 1회 -> 내용/사진 보존 -> 새 버전 저장 -> 새 보고서 열람 -> 실제 다운로드 bytes 일치를 확인합니다. 기존 버전과 생성 호출 수는 그대로이고 독립검증/유료 호출은 없습니다. 단위 시험은 내용 변경 거절·최신 검사 미완료 보고서 편집·쪽 번호 글자 크기·브라우저 실패 시 호출 차단·재시작 중단 기록을 확인합니다. 서비스 시험은 브라우저 준비 실패 시 기존 서버를 멈추지 않는 것을 확인합니다. 공개 화면은 합성 자료의 모의 시험이며 운영 화면이나 실제 Terra 품질 검증으로 표시하지 않습니다. 기존 SG6 파일은 교체하지 않았습니다.

최종 회귀: 단위·HTTP 250개, 실행기 13개 모두 통과. 현재 소스·증거 지문 일치. 실제 유료 호출·운영 적용은 확인하지 않았습니다.
