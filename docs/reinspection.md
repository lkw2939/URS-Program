# 정의서 재점검 및 미완료 조건

첨부 정의서는 기존 원본과 동일하다. 최초33개+추가5개와 정의서19개 장의 기존 대조 기록을 다시 확인하고 이번에는 실제 검증 입력·근거·수정 전파 경로를 점검했다. 모든 미발견 결함이 없다는 보장은 하지 않는다.

## 확인하고 보완한 누락

| ID | 원문 기준 | 문제 | 처리 |
|---|---|---|---|
| REVIEW-01 | V-3, XIV-1 근거 있는 PASS | 빈 독립 검증 이유를 허용 | 공백만 있는 근거 거부·다음 단계 차단 |
| REVIEW-02 | III-2, V-2, VII-4, VIII-3 표/제품 관계 | 문서 전체 검증·분석에 격자 구조 미전달 | 행/열/병합 격자·셀ID/좌표·이미지 메타데이터 전달 |
| REVIEW-03 | III-2, XIV-3 원본 신뢰·단계 통과 | 독립 검증·분석 시작 전 미리보기 재검사 누락 | 개수/해시 확인, 손상 시 AI 요청 전 차단 |
| REVIEW-04 | VI-3, XI 수정 영향 | 수정 후 표 구조에 옛 추출 문자가 남을 수 있음 | 현재 직원 수정 원문을 구조 문맥에 반영 |

이미지 메타데이터 전달은 실제 이미지 내용의 독립 시각 검증 완료를 의미하지 않는다. 실제 시각 품질은 원본/번역/최종 출력 대조가 필요하다. 문맥 데이터가 늘어 요청 한도 초과가 되면 기존 한도에 따라 차단하며 일부 원문을 조용히 생략하지 않는다.

## 작업 규칙 재확인

시작 전 체크리스트/첨부/소스해시 대조→발견점과 통과 조건 보고→구현→관련31개 시험 통과→전체 순서 회귀. 실패·0개·건너뜀·예상 실패는 후속 단계 실행을 차단한다. 실제 업무에서는 미해결/미실행/조건 부족을 PASS로 바꾸지 않는다. 합성 자격으로 실제 회사 문서를 승인하지 않는다.
