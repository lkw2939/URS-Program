# 보고서 생성 프로그램의 레거시 사진 로더 정리

이전의 개별 report.html 수정은 프로그램 패치가 아니었습니다. 이번 변경은 Processing.report에 직접 연결됩니다. 원본 PDF와 저장 프롬프트·모델·출력 한도·대기 정책·번역·디자인 방식은 바꾸지 않습니다. 유료 자동 재시도도 하지 않습니다.

## 새 생성 경로

Terra 응답 원본을 보존 → image_presentation.prepare → bind_images → 최종 HTML Chromium 검사(JS 끔/켬, 좁은 화면 포함) → 새 이력 저장 → 정상 결과만 현재 보고서로 선택합니다.

prepare는 실제 결함의 식별자인 pdf-file 입력과 pdfjsLib/pdf.min.js 로더가 함께 있는 경우에만 작동합니다. PDF 선택 전용 aside.toolbar, PDF 로더 스크립트, 선택 대기용 figure-status만 제거합니다. .figure img와 .figure img.ready 선택자의 숨김 선언만 표시로 정리하며 이미지 크기/위치·본문/표/캡션·페이지 구성을 바꾸지 않습니다. 원본 도면과 캡션이 든 선택 UI를 임의로 통째 삭제하지 않습니다. 다른 스크립트와 본문의 PDF.js 설명은 유지합니다. 문서 바깥의 마크다운 펜스는 실제 닫힌 HTML이 있는 경우에만 제거하며 끝 태그를 새로 만들지 않습니다.

정상 응답은 prepare 전후 bytes가 같습니다. 인식하지 못하는 방식, 선행 UI가 남은 경우, 그림이 여전히 숨겨진 경우, 페이지 넘침/A4 불일치 등은 기존 검사에서 차단합니다. 모르는 CSS를 일반적으로 재작성하거나 사진을 다른 위치에 추가하지 않습니다.

웹은 detail 응답의 image_presentation_version을 표시합니다. 클라이언트 상수로 서버 적용을 추정하지 않습니다. 기존 보고서에 정리가 적용됐는지는 해당 보고서 메타데이터를 별도로 표시하므로, 새 서버 코드와 과거 저장 파일을 혼동하지 않습니다.

## 원본과 변경 기록

report.raw.html은 Terra 원본입니다. 정리가 발생한 경우 report.prepared.html과 image-presentation JSON을 추가 보존합니다. 최종 report.html은 prepared에 원본 사진 주소를 넣은 결과입니다. 메타데이터와 검증 기록은 raw/prepared/final 해시, 처리 버전, 제거/변경 유형을 기록합니다. only_image_addresses_changed는 이 경우 false이며, 정상 응답에서만 true입니다. UI에도 PDF 재선택 코드·사진 표시 정리 적용을 표시합니다.

열람·검증 입력 무결성은 raw에서 동일 버전 prepare를 재현하고 prepared bytes/기록 해시를 비교한 뒤 원본 이미지를 연결해 최종 HTML과 비교합니다. 직원의 후속 선택 수정 이력도 이 부모 증거를 검증합니다. 정리된 최종본을 독립검증에 전달하며 raw를 수정본인 것처럼 보내지 않습니다.

## 확인

- 실제와 동일한 PDF 선택 UI·PDF.js·ready 클래스·display:none을 가진 합성 응답을 실제 생성 요청 경로에 주입합니다.
- 로그인 → 생성 → 저장 → HTML 확인 → 사진 두 장과 벡터 도면의 실제 픽셀 → 다운로드 파일 일치 → 인터넷/JS 없는 표시를 확인합니다. 정상 응답도 별도로 그대로 시험합니다.
- 원본/본문·표·캡션·주소 유지, 알 수 없는 UI 보존, 끝 태그 미조작, 원본/중간본 변조 감지, 선택 수정과의 연결을 단위 시험합니다.
- 실제 고객 SG6의 raw/최종 HTML을 비공개 로컬에서 같은 함수로 처리하여 28개를 개별 스크롤·표시 검사했습니다. 고객 PDF/HTML/스크린샷은 저장소나 공개 소스 패키지에 넣지 않습니다. 이 시험은 운영 DB 적용이나 번역 품질 검증을 뜻하지 않습니다.

기존 운영 보고서·DB·프롬프트는 수정하지 않았으며 유료 호출도 없었습니다. 운영 서버 접속/실행 권한은 별도 확인되지 않았으므로 소스 반영과 실제 운영 적용을 구분합니다.

최종 전체 시험: 단위·HTTP 220개, 실행기 10개 모두 exit_code=0. 현재 소스/증거 해시 일치. 실제 유료 생성·운영 DB 변경은 없음.
