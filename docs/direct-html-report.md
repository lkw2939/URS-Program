# 원본 PDF 기반 직접 HTML 보고서

## 직원 화면과 실행 순서

보고서 프롬프트 설정에서 직원별 프롬프트를 저장합니다. 앞뒤 공백/줄바꿈을 포함한 원문을 버전별로 보관합니다. 기본 저작 프롬프트는 주입하지 않습니다.

원본 보관 → HTML 보고서 생성 → 독립 검증 → 기술 분석 → 직원 승인, 총 5단계입니다.
추출/원문 보완 UI, review-extraction API, extract/translate 실행, 블록 번역 수정 및 고정 Word/PDF 제작은 삭제했습니다.
기존 DB의 옛 추출·번역·출력물은 삭제하지 않습니다. 백업 검사는 역사 자료의 무결성 확인을 위해 예전 레코드 형식을 읽을 수 있지만 새 텍스트를 추출하는 기능은 없습니다.

## 실제 보고서 API 요청 계약

Responses API의 user content는 다음 3개입니다.
1. input_file: 업로드한 원본 PDF 전체 bytes의 base64와 원본 파일명.
2. input_text: 웹에 저장한 보고서 프롬프트 원문 그대로.
3. input_text: urs-image:PAGE:INDEX 주소 규약과 실제 원본 그림의 쪽/번호/bbox 목록.

보고서 요청에는 instructions, SYSTEM, 용어집, 텍스트 추출 결과, 기존 번역, 블록 번역, 프로그램 번역/디자인 규칙을 넣지 않습니다.
모델은 기존 URS_OPENAI_MODEL 설정을 그대로 사용합니다. 실제 Terra 모델 ID/접근 여부는 유료 호출 없이 확인하지 않았습니다.
max_output_tokens=5000 및 기존 비용 예약/한도 통제는 유지합니다. 첨부 이미지 축소 실험이나 모델 설정 변경은 하지 않았습니다. 별도 input_image 첨부 대신 원본 PDF 자체를 보냅니다.
모의 응답의 실제 전송 본문은 evidence/html-request-contract.json에 기록합니다(가짜 모델/합성 PDF만 포함, 인증 헤더 없음).

## HTML과 원본 그림

PDF의 raster 이미지와 연결된 벡터 도형 영역을 원본 페이지 좌표에서 PNG로 잘라 둡니다. 페이지의 문자를 읽거나 OCR하거나 원문 텍스트를 저장하지 않습니다.
쪽별로 위→아래, 왼쪽→오른쪽 순서의 안정된 번호를 사용합니다. 멀리 떨어진 벡터 도형을 임의로 하나의 그림이라고 추정해 합치지 않습니다. 실제 복잡한 PDF의 영역 식별 품질은 미검증입니다.

report.raw.html은 모델 문자열의 UTF-8 bytes 그대로입니다. report.html은 원본 문자열에서 실제 이미지 태그의 src/href 주소 범위만 data:image/png;base64,...로 치환합니다.
HTML 파싱은 원래 주소의 오프셋을 찾는 데만 쓰며, DOM 재직렬화·본문/표/캡션/CSS 변경·그림 추가·페이지 재배치는 없습니다. 같은 토큰이 본문/주석/CSS 문자열/스크립트에 있어도 바꾸지 않습니다.
못 찾은 그림은 원래 주소를 유지하고 URI와 HTML 위치를 image-bindings에 기록하며 직원 화면에 표시합니다. 미연결이 있으면 검증 통과/최종 승인을 차단합니다.

직원 기본 결과는 최종 HTML iframe입니다. 다운로드는 최종 HTML과 Terra 원본 HTML을 각각 제공합니다. 사용자 요청의 PDF.js/로컬 파일 선택을 위해 분리된 iframe에서 인라인 스크립트·정해진 CDN·worker를 허용합니다. 부모 직원 화면 접근은 차단하며 HTML bytes는 변경하지 않습니다.

## 검증/기술 분석과 기존 기록

별도 단계는 각각 원본 PDF와 모델 HTML을 대상으로 실행하고 JSON 검토 결과만 저장합니다. 보고서 본문을 자동 수정하거나 재생성하지 않습니다.
보고서 프롬프트 저장, 로그인, 문서 조회, 앱 재시작은 기존 보고서를 재생성하지 않습니다.
직원이 명시적으로 보고서 생성을 다시 누르면 새 리비전을 만들고 과거 HTML/분석/검증 자료는 남깁니다.
새 HTML 단계의 check ID는 html-v1/pdf-html-v1입니다. 기존 definitions/results/artifacts/approvals 행을 시작 시 수정/삭제하지 않고, 새 작업의 활성 단계 정의만 메모리에서 선택합니다. 과거 성공/승인을 새 HTML 결과의 성공으로 취급하지 않습니다.
운영 DB를 열거나 기존 고객 보고서를 생성/덮어쓰는 작업은 수행하지 않았습니다. 모든 실행 시험은 임시 DB/합성 PDF/모의 응답입니다.

## 시험 범위 변경

삭제된 기능을 요구하던 텍스트 추출·블록 번역·고정 Word/PDF 시험은 새 원본 PDF/HTML 요청 계약·이미지 전용 crop·주소 치환·회귀 보존 시험으로 대체했습니다. 과거 112개 시험과 현재 시험 수는 동일한 기능 범위가 아닙니다.
기존 로그인/권한/CSRF/백업/복구/단계 게이트/전문가 자격 시험은 유지하고 새 HTML 출력물에 맞춰 검증합니다.
LibreOffice 제작 경로는 제거되었으므로 현재 최종 실행기는 단위/HTTP → Chromium → HTML/PNG 재열기입니다. 과거 로그는 evidence/history-v1에 보존합니다.
