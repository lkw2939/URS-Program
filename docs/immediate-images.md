# 생성 한 번으로 사진·도면이 보이는 최종 HTML

새 보고서는 원본 PDF 업로드 및 기존 비용 확인 후 **보고서 생성** 한 번으로 모델 HTML 작성 → 원본 그림 연결 → 최종 HTML 저장 → 표시 검사를 수행합니다. 보고서 안에서 PDF를 다시 고르거나 별도로 사진을 첨부하지 않습니다. 자동 유료 재시도는 없습니다.

모델 입력의 출력 조건은 `a4-inline-images-v2`입니다. 저장한 프롬프트 원문은 보존하되, 그 안에 과거 PDF.js/원본 PDF 재선택 요구가 있어도 이번 이미지 방식이 우선임을 명시합니다. 원본 PDF와 프롬프트가 그대로 전달되는지는 실제 OpenAI 어댑터의 모의 요청에서 비교합니다. 모델·effort·출력 한도·단가를 바꾸지 않습니다.

모델은 그림 자리에 `<img src="urs-image:쪽:번호" alt="설명">`만 둡니다. PDF 선택 input, PDF.js/worker 로딩, canvas/picture/source/data-src/배경 그림 대체, 사진 숨김 CSS, ready 클래스나 JavaScript 이벤트를 기다리는 방식은 요구 조건에서 금지합니다. 프로그램은 처음 올린 PDF에서 사진·벡터 도면 영역을 PNG로 가져와 지정 src만 data URL로 치환합니다. 원본 모델 HTML은 그대로 보관하고, 본문/표/캡션/CSS를 보정하지 않습니다.

검사는 다음처럼 분리합니다.

- 원본 HTML의 이미지 슬롯이 일반 img src인지, 파일 선택 UI·PDF.js 스크립트·이벤트 의존 등이 있는지 검사합니다.
- 이미지 연결 후 최종 HTML을 Chromium으로 실제 렌더링합니다. 외부 연결을 막고 JavaScript를 끈 상태와 켠 상태 모두, 데스크톱과 좁은 화면에서 이미지 로딩·표시 영역·상위 요소의 숨김/투명도를 검사합니다. 페이지 구역 밖에 숨긴 그림도 검사합니다.
- 기존 A4 크기·넘침 검사는 유지합니다. 표시하지 못하는 그림의 페이지·그림 번호와 이유를 layout-audit에 남깁니다. 정상 결과에만 PASS를 기록하고 현재 보고서로 전환합니다. 표시/배치 문제는 NEEDS_REVIEW, 브라우저 검사 실행 불가는 UNVERIFIED입니다.
- 잘못된 응답도 원본/이미지 연결본은 검사 자료로 보존하며 완료본으로 위장하지 않습니다. 이전 정상 보고서를 유지하고 새 시도의 이유를 화면에 보여줍니다. 자동 재생성하지 않습니다.

## 실제 버튼과 픽셀 시험

`tests/browser_immediate_images.py`는 임시 DB/합성 PDF/모의 OpenAI 응답으로 로그인 → 무료 비용 확인 → 생성 클릭1회 → 최종 저장 → **HTML 확인** 클릭을 시험합니다. 같은 쪽의 서로 다른 빨강/파랑 사진과 벡터 사각형·대각선 도면을 각 주소에 연결하고 브라우저 표시 크기와 실제 이미지 픽셀을 확인합니다. PNG가 단순히 내장됐다는 검사만으로 끝내지 않습니다.

다운로드 bytes가 저장본과 같은지 확인한 후 같은 HTML을 오프라인·JavaScript 비활성 브라우저 문서로 렌더링해 동일한 사진/도면 표시를 재검사합니다. 관리 브라우저의 file:// 접근은 정책으로 막혀 있으므로, 다운로드 파일 bytes를 브라우저 문서에 그대로 읽어 표시한 시험입니다. 일반 파일 프로토콜 접근까지 통과했다고 표시하지 않습니다.

[evidence/immediate-original-images.png](evidence/immediate-original-images.png)는 합성 자료입니다. [evidence/immediate-image-check.json](evidence/immediate-image-check.json)은 생성 횟수, HTML 확인 클릭, 픽셀 점검 및 원본/최종본 동일성 근거입니다. 실제 고객 번역 품질이나 실제 Terra가 모든 요구를 준수한다는 인증은 아닙니다.

기존 SG6 리비전1, 기존 실패/비용 기록, 직원 답변, 웹 저장 프롬프트는 수정하지 않습니다. 이번 변경이 기존에 내려받은 리비전1 HTML의 CSS를 고쳐 준다는 뜻은 아닙니다. 실제 SG6 재생성이나 유료 API 호출은 하지 않았습니다. 운영 배포 여부는 소스 푸시와 별도입니다.
