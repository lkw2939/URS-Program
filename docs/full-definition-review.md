## 아직 완료로 판정할 수 없는 부분

- 실제 고객 문서의 전체 원문/그림 문자/복잡한 표 및 레이아웃 대조. 현재 번역은 본문·표 재구성과 원본 페이지 부록 방식이며 원본과 픽셀 단위로 같은 배치를 보장하지 않는다. 다단 문서 등 읽기 순서가 모호한 실제 레이아웃은 원문 대조가 필요하다.
- 공식 한미 자료의 원문·판본·적용 문맥 검토와 승인 용어집. 미열람 후보는 승인하지 않았다.
- 전문가 문장 의미99% 이상·중대 기술/안전 오역0의 실제 모델 평가.
- 실제 직원 접속 환경과 실제 고객 보고서의 운영 인수.
- API/결제/모델/공급자 자동충전은 이번 작업에서 제외.

직원 최종 승인 기록은 검토한 본문을 다시 작성하지 않고 뒤에 기록 페이지를 추가한다. 생성 시점 미승인 표시와 사후 승인 기록의 시점을 구분한다. 최종 파일 해시는 승인 근거와 함께 저장하며, 수정/재검증/손상/기존 자격 변경 시 최종 다운로드는 차단한다. 전자서명 기능을 의미하지 않는다.
