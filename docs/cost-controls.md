# 실행별 비용 확인과 사용량 정산

`URS_AI_BUDGET_USD`는 **한 번의 Responses 실행에 대한 예상 상한**입니다. 문서 누적 달러 한도가 아닙니다. 기존 설정값 10을 20으로 올리지 않으며 모델, effort, 출력 한도도 이 작업에서 변경하지 않습니다. 문서의 요청 횟수 안전 상한 120회는 별개로 남습니다.

## 무료 비용 확인 → 별도 실행

보고서 검토 화면에서 각 단계의 **비용 확인 (무료)**를 먼저 누릅니다. 원본 PDF와 실제로 전송할 입력을 `POST /v1/responses/input_tokens`로 보내 입력 토큰 수를 확인합니다. 이 엔드포인트는 OpenAI 공식 안내상 무료이며 추론 결과를 생성하지 않습니다. 무료 계산 단계는 ai_usage 실행 예약 행을 만들지 않습니다. 단순 화면 열기/GET 조회로는 문서를 외부 전송하지 않습니다.

입력 계산액 = 제공된 입력 토큰 수 × 설정 입력 단가 / 1,000,000.

이번 1회 예상 상한 = 입력 계산액 + max_output_tokens × 설정 출력 단가 / 1,000,000.

실제 출력 길이는 미리 알 수 없어 최대 출력 비용을 분리해 보여줍니다. 캐시 할인은 사전 상한에서 적용하지 않습니다. 설정 단가는 회사가 해당 모델·서비스에 대해 확인해야 하며, 이 값은 OpenAI 청구서나 계정 잔액을 자동 확인한 값이 아닙니다. 실제 계정 잔액 $3.24를 URS 한도로 증액할 수는 없습니다. 잔액은 제품에 하드코딩하지 않았습니다.

모델·effort·출력 한도·입력·설정 단가를 포함한 요청 지문과 비용 확인 결과를 30분 캐시합니다. 새 입력이나 설정, 만료된 확인이면 실행 전에 다시 확인해야 합니다. 실행 버튼은 무료 계산이 끝나기 전 비활성화됩니다. 서버도 화면에서 확인된 요청 지문을 실제 요청과 대조합니다. 무료 계산 실패/지원되지 않는 모델/입력 형식이면 예상액 미확인으로 남기고 유료 실행하지 않습니다. 바이트 수를 토큰으로 바꾸는 폴백은 없습니다.

## 사진을 긴 글자로 보내지 않음

기존 최종 HTML의 사진 base64를 input_text로 그대로 보내는 방식도 함께 정리했습니다. 검증 전송용 복사본에서는 내장 이미지 주소를 `urs-review-image:...` 식별자로 바꾸고 같은 이미지 bytes를 각각 input_image로 전달합니다. HTML과 이미지의 대응 라벨을 함께 보냅니다. 이미지 개수·해상도·PNG 원본 bytes·비율을 줄이거나 재압축하지 않습니다. PDF는 원본 input_file 그대로 전송합니다. PDF와 별도 이미지 입력은 토큰 계산 API가 처리하며 base64 문자열 길이를 글자 토큰으로 추정하지 않습니다.

저장한 Terra raw/final HTML은 바꾸지 않습니다. 검증 결과의 대상은 화면의 저장 리비전과 그 final HTML SHA입니다. 보고서 본문/CSS/캡션은 그대로이고 전송 복사본에서만 주소를 이미지 입력 ID에 연결합니다. 전송할 수 없는 내장 이미지 형식은 명시적으로 차단합니다. 별도 ChatGPT A4 파일을 자동 사용하지 않습니다.

## 사용량 정산 / 미확인 기록

새 호출은 요청 당시 입력·출력·선택적 캐시 단가, 모델, 입력 토큰 계산 결과, 출력 한도, 실행 한도를 ai_call_costs에 보관합니다. 기존 ai_usage.reserved는 최초 예상액 증거로 유지합니다.

- 정상 응답과 실패/불완전 응답 모두 input_tokens/output_tokens가 확인되면 요청 당시 단가로 정산합니다. 출력 추론 토큰은 output_tokens에 포함되므로 다시 더하지 않습니다.
- JSON/HTML 처리 실패가 응답 뒤에 발생해도 응답에서 확인한 usage를 보존하고 정산합니다.
- 시간 초과·부분 사용량 등은 actual_cost_usd=null, 미정산으로 유지합니다. 무조건 0원으로 반환하지 않습니다.
- 과거 호출에 usage가 있어도 당시 단가 스냅샷이 없으면 legacy_rates_unknown입니다. 현재 단가를 과거 단가로 소급 확정하지 않습니다.
- cached_tokens가 있고 당시 캐시 단가가 없거나, 기본이 아닌 서비스 계층 단가가 확인되지 않으면 미정산으로 유지합니다. 선택적 URS_AI_CACHED_INPUT_USD_PER_MILLION은 해당 단가를 확인한 경우에만 설정합니다.

**누적 사용량·정산 이력 (조회만)**에서 최초 예상액, 토큰, 정산액, 미정산 이유를 따로 봅니다. 정산액 합계에 미확인 예약액을 더하지 않습니다. 이 이력은 다음 실행의 $10에서 차감되지 않습니다. 장부 초기화·과거 예약 삭제는 없습니다. 검증 기록 JSON의 ai_cost_history에도 숫자 근거가 포함됩니다. API 키·PDF/HTML 본문은 비용 기록에 남기지 않습니다.

## 시험 범위

모든 시험은 임시 DB와 모의 토큰 계산/추론 응답으로 합니다. 실제 SG6 문서의 새로운 토큰 수, 실제 모델 API 연결, 계정 잔액을 확인했다고 표시하지 않습니다. 실제 비용 계산은 적용한 운영 웹의 무료 비용 확인 버튼에서 가능합니다. 유료 실행 버튼은 별도입니다.
