# 3~9단계 실행 전 체크리스트

모든 항목 필수. 초기 상태 UNVERIFIED. 실제 실행 근거가 있을 때만 상태 변경. 합성 입력과 실제 OpenAI/고객 문서 평가를 구분한다. 후속 기능의 격리 개발 시험은 가능하지만 앞 단계 미통과 문서의 정식 처리는 서버가 차단한다.

| ID | 요구사항 | 시험 입력 및 기대 결과 |
|---|---|---|
| S3-01 | A1 A4 | 여러 페이지의 알려진 텍스트 PDF → 모든 페이지/문장/좌표/원문 ID 보존 |
| S3-02 | A2 | 표와 병합 셀 PDF → 셀 좌표/내용/셀 연결 보존, 불확실한 표는 검토 대상으로 유지 |
| S3-03 | A3 | 그림/도면 포함 PDF → 원본 페이지 렌더링 보존, 이미지·원문 위치 연결 |
| S3-04 | A1 | 스캔/문자 없는 페이지 → 누락을 PASS하지 않고 NEEDS_REVIEW, 번역 차단 |
| S4-01 | B1~B4 | 영어/인도네시아어 전체 블록 → 모든 원문 ID의 한국어 번역, 숫자·제품 코드 유지 |
| S4-02 | B1 | 실제 승인 OpenAI API 호출 → 실제 응답과 사용량 기록, 연결·비용 설정 없으면 BLOCKED |
| S5-01 | C1 C2 C4 | 별도 검증 요청, 부정문/조건/수치 오류 → 근거 오류 기록 및 제한된 수정·재검증 |
| S5-02 | C7 | 전문가 정답 평가집 → 의미 정확도 99% 이상 및 중대 안전 오역 0, 평가집 없으면 미달성 |
| S5-03 | C5 C6 | 미해결/재시도 초과/API 오류 → 다음 단계·승인 차단 |
| S6-01 | D1 D2 | 설비/공정 URS → 고객 요구와 AI 해설 분리, 모든 원문 참조 유효 |
| S6-02 | D3 D4 | 같은 제품 충돌 치수, 다른 단위 속도 → 문맥별 충돌/잠재충돌 구분, 근거 연결 질문 생성 |
| S7-01 | F1 F2 | 번역 블록 선택 → 해당 원본 페이지/좌표 강조 |
| S7-02 | F3 F4 F5 | 직원/AI 수정 → 변경 이력, 리비전 증가, 기존 검증/분석/출력/승인 무효화 |
| S8-01 | E1 E2 E3 | 한국어 번역본 및 분석 보고서 → 내용·수치·표·그림 보존, 원문과 해설 구분 |
| S8-02 | E4 E5 | DOCX/PDF 실제 열기 → 한국어·이미지·내부 링크·개요·본문 확인, 시각 품질 검토 |
| S9-01 | G3 G4 | 미검증 출력 및 이전 버전 승인 요청 → 차단, 최신 필수 검증 후 직원 승인만 허용 |
| S9-02 | 전체 | 실제 고객 URS 전체 흐름 → 모든 필수 항목 및 직원 검토 근거 확보 후 최종 완료 판정 |

검증용 PDF/정답/실제 API 설정이 없는 항목은 합성 시험으로 대체해 PASS하지 않는다. 33개 요구사항 전체의 최종 판정은 별도 결과표로 기록한다.
